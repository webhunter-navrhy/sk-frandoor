# FranDOOR – koncept
Brief: zastaralý WP web (2018) truhlárstva z Huncoviec; dvere, vstavané skrine, podlahy; Kežmarok a Poprad. Brand: červená #AA0404, text #6F6666, Quicksand, logo jen textem (soubor loga web nemá).
Koncepty: A) akordeon dverných krídel v hero (dvere = hlavný produkt) B) veľké fotky po oboroch, editoriálne C) cenník-first.
Volím A: panely ako krídla dverí, reálne fotky realizácií, červená ako akcent, bez vymyšlených čísel.
